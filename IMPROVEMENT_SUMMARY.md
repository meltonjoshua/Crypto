## 📊 **Trading Signal Logic**

The application uses a sophisticated scoring system combining multiple indicators:

1. **RSI Analysis**: 
   - Oversold (<30) = +2 points (BUY signal)
   - Overbought (>70) = -2 points (SELL signal)

2. **MACD Analysis**: 
   - Bullish crossover = +1 point
   - Bearish crossover = -1 point

3. **Moving Averages**: 
   - Short MA > Long MA = +1 point (bullish trend)

4. **Bollinger Bands**: 
   - Price near lower band = +1 point (oversold)

**Signal Generation:**
- Score ≥ 3: **STRONG BUY** 🟢
- Score ≥ 1: **BUY** 🟡
- Score ≤ -3: **STRONG SELL** 🔴
- Score ≤ -1: **SELL** 🟠
- Score = 0: **HOLD** ⚪
